# Annotated Transformer

## 项目信息

- **GitHub**: https://github.com/harvardnlp/annotated-transformer
- **描述**: An annotated implementation of the Transformer paper
- **主要语言**: Python
- **默认分支**: master

## 项目概述

Transformer论文的详细注释实现，是理解Transformer架构的经典教程。

## 核心内容

- Transformer架构详解
- Self-Attention机制
- Position Encoding
- Multi-Head Attention
